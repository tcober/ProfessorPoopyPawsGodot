; Alembic Town, THE FLOOR — 80x56 tiles (1280x896 px), Basil's origin village seen
; from the ground: a forest-floor clearing in PERMANENT GREEN DUSK under the four
; great trees' closed crown. The lanes, the fountain square, the three shops, the
; cottages, the well and the stall are all down here; the RING DECKS are not — the
; canopy is its own scene now (assets/maps/canopy.txt, the 2026-08-23 split), and
; the four rope ladders are TRAVEL MOUTHS between the two.
;
; THE SPLIT (2026-08-23, repealing DESIGN.md's old REJECTED bullet — see DESIGN.md
; -> "STACKED WALKABLE STOREYS"): the ground map carries NO canopy stratum at all.
; Each great trunk is 4 solid `j` columns typed from row 6 down to its `!` foot,
; with the rope ladder's `z` lane inside them. The shaft ART is baked from row 0,
; over the border's leaf mass, and runs off the top of the map — a tree with no
; visible top reads as too tall for the screen, which is the point. The `z` runs
; are the old grid's, verbatim; a body climbs them for real, and a travel zone at
; each run's TOP two rungs (anchors top1..top4) hands the climb to the canopy
; scene mid-ladder, so you leave climbing and arrive climbing.
;
; `z` carries NO stratum token any more: a link must border two strata and the
; second storey lives in another file now. The climb mechanics never cared — 
; PartyMember._climb keys on the TERRAIN name `ropeladder`, and AIBrain's
; never-stop rule now keys on the terrain too.
;
; PERMANENT DUSK IS DIEGETIC: the crown closed over the clearing a generation
; ago, so the floor never sees full sun — the lamps burn at noon (honest fire,
; so they burn drained too) and the fireflies never really leave. The palette
; carries the hour; scene code adds the fireflies (components/fireflies.gd).
;
; Everything else — the lane web, the square, the buildings, every cast anchor —
; is the pre-split grid, kept on purpose: ten shipped beats choreograph across
; these lanes and their anchors are load-bearing by NAME (see the fest twin).
;
; Byte-locked twin: town_fest.txt (same grid, festival palette). Edit both in
; the same commit — _check_art.py enforces it.
