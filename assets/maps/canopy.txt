; THE BOUGHS — Alembic Town's canopy, 80x32 tiles (1280x512 px): the second half
; of the 2026-08-23 two-scene split (the ground is assets/maps/town.txt). Four
; RING DECKS at one deck height, joined pole-to-pole by ROPE BRIDGES with a
; mid-span landing, in a sea of leaf — and below all of it, THE DROP: the void
; between the platforms renders the town itself, thirty feet down and dusk-dim,
; lit windows and lane lanterns and all. That view is the answer to the old
; REJECTED-split objection about sense of place: climbing the ladder does not
; take you somewhere else, it shows you where you already were.
;
; THE RING BLOCKS ARE THE PRE-SPLIT GRID'S, VERBATIM (12x9, walkable cells
; rasterized from the very ellipse tree_ring draws — see town.txt's pre-split
; header in git for the full derivation; the doctrine lives in DESIGN.md ->
; "STACKED WALKABLE STOREYS"). Do not "tidy" the ring rows: they are derived,
; and _alembic.assert_canopy checks this grid against ring_cells' mask.
;
; NEW SINCE THE SPLIT, in this grid only:
;   `E`  the BRIDGE GATES — two rim cells per bridged pole, retyped walkable.
;        Same terrain as `y`/`R` (ringedge -> leaf), the O/U/L twin idiom, so
;        the ring's yRE border stays ONE component and the rail emits per tree.
;        They are mask exceptions exactly like the ladder landing: named off
;        the bridge, never typed as a row.
;   `=`  the BRIDGE SPANS, 2 rows deep, walkable; tree_bridge art is blitted
;        one cell wider each side so its bearer beams land on the gates.
;   `n`  the LANDING between trees 2 and 3 (tree_platform), with the hook
;        lantern's h/H twins standing on it (`decklamp` renders deck — a
;        hooklamp cell here would punch a GRASS square through the boards).
;   `_`  THE DROP. Solid. Interior drop cells are repainted by the recipe's
;        drop-field pass (the town far below); boundary cells keep the leaf
;        lattice, so every void pocket is fringed in foliage. A body can never
;        stand here — the fascia crescents, the rails and the descending
;        trunks are what say "down".
;
; The trunks continue BELOW each ring (rows 19-22) and the `z` runs ride them:
; 7 rungs from the fascia cut down into the gloom. The travel zone sits on the
; BOTTOM two rungs (anchors head1..head4) and hands the climb to the ground
; scene mid-ladder; below row 22 the trunk art fades into the drop. A canopy
; `z` run therefore ends against SOLID void — the old "ladder ends on walkable
; ground" rule holds only on the ground map now.
;
; There is ONE stratum up here (everything walkable is the default ground
; stratum): a second storey needs a second storey to be ambiguous with, and
; that one lives in another file now. `z` carries no link token for the same
; reason — see town.txt's header.
;
; Byte-locked twin: canopy_fest.txt (same grid, festival palette; it adds the
; goose_hide anchor on tree 3's east arc). Edit both in the same commit.
